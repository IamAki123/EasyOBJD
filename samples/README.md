# Copy-in samples

These files are **not** inside the JitPack AAR. Copy them into TeamCode (`org.firstinspires.ftc.teamcode`).

| File | When |
| --- | --- |
| [EasyOBJDCluster.java](EasyOBJDCluster.java) | Always. 12×12 grid overlay, D-pad HSV, cluster X/Y. |
| [EasyOBJDUserConfig.java](EasyOBJDUserConfig.java) | Always. Your robot's camera height, tilt, focal, HSV, ball size. |
| [EasyOBJDTuner.java](EasyOBJDTuner.java) | Optional. MASK overlay while nudging HSV. |
| [EasyOBJDCalibrateSample.java](EasyOBJDCalibrateSample.java) | Optional. Tape focal length and tilt. |
| [EasyOBJDRangeTest.java](EasyOBJDRangeTest.java) | Always, once per robot. **Configure your robot or distances will be wrong.** Tape two distances, press A, paste the solved tilt / focal. |
